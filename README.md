# Model Recommend

## 1. Project

Model Recommend helps Concentrate AI's business customers choose an AI model. A product manager submits a brief (budget ceiling, latency ceiling and task description); the system benchmarks the models of every vendor the company's IT security reviewer has approved and returns a ranked shortlist with a 0–100 fit score and the reasoning behind each rank.
